# dsh-md-notes 冒烟测试清单

> 每次改动后、发布前，按本清单逐项对照验证。约定：✅ = 符合预期；❌ = 异常（记录现象/报错）。
> 依赖 [使用文档](usage.zh.md) 理解每项的含义，本文只给「怎么做 + 看什么」。

## 0. 前置准备

- [ ] 插件已从本地源码 link 进 profile（`dsh plugin --profile web add ./dsh-md-notes`）
- [ ] 已 `npm run build`（host + client 都重新构建）
- [ ] 已**重启 dsh web**（host 侧改动必须重启）
- [ ] 浏览器**强制刷新**页面（client 侧改动）
- [ ] dsh 侧边栏已存在至少一个工作区

## 1. 侧边栏入口

| 步骤 | 预期 |
|---|---|
| 看侧边栏底部（设置上方） | 出现「笔记」入口，图标正常 |
| 悬停入口 | 显示「MD 笔记」tooltip |
| 展开态，cordis 面板入口与笔记入口并存 | **各占一行**，不互相挤压/溢出（issue #2 回归；插件以 `:has + data-slot` 规则兜底，见 `client/index.ts` sidebar-footer 标签） |
| 仅装本插件时 | 笔记入口独占一行（兜底规则对单入口视觉无变化） |
| 折叠态侧栏 | cordis 与笔记两图标并排居中，正常 |
| 存在超长标题的会话 | 会话标题省略号截断，侧栏宽度不拉宽（**issue #1 回归**）；DevTools 检查 SidebarRoot 元素无插件写入的 inline 样式 |

## 2. 笔记管理器

### 2.1 打开与列表

| 步骤 | 预期 |
|---|---|
| 点侧边栏「笔记」入口 | 打开全屏管理器，左栏按工作区分组显示笔记 |
| 无工作区时 | 显示「暂无工作区」引导 |
| 工作区行文件夹图标 | 点击可折叠/展开该组 |
| 工作区行 git 图标 | 配了 git 仓库的工作区显示（笔记计数后）；未配仓库不显示 |

### 2.2 新建 / 编辑 / 预览 / 保存

| 步骤 | 预期 |
|---|---|
| 点工作区行「+」 | 弹出「新建笔记」弹窗（标题默认「未命名笔记 <日期>」+ 可选文件名），点「创建」进入编辑态 |
| 文件名填一个已存在的文件名 | 红字提示「同名文件已存在」，创建按钮禁用 |
| 编辑框输入 markdown，点「保存」 | 提示「已保存」，左侧列表刷新 |
| 切到「预览」Tab | markdown 渲染正确（表格/公式/代码高亮） |
| 关闭管理器再打开 | 笔记仍在（已持久化到 `.dsh-notes/`） |

### 2.3 删除

| 步骤 | 预期 |
|---|---|
| 悬停列表项点 🗑 | 弹确认框（不可撤销提示） |
| 确认删除 | 笔记消失，文件被删除 |

---

## 3. 记入笔记（对话 → 笔记）

| 步骤 | 预期 |
|---|---|
| 在任意回答下方点「笔记」图标（复制按钮旁） | 弹出选择面板，按工作区分组列出笔记 |
| 选一篇笔记，点「写入笔记」 | 按钮显示「写入中…」，成功后左侧出现绿色「已写入 ✓」再自动关闭 |
| 打开该笔记 | 末尾追加了一段 `---` + 时间戳标题 + 👤提问 + 🤖回答；**无思考(reasoning)内容** |

---

## 4. @ 引用笔记（笔记 → 对话）

| 步骤 | 预期 |
|---|---|
| 输入框输入 `@` | 候选菜单列出当前工作区笔记（文件图标，标题 + 文件名） |
| 输入文字过滤 | 候选按标题/文件名过滤 |
| 选中一篇 | 输入框出现笔记 chip（前置插件 logo） |
| 输入部分工作区名（如 `@dsh-pl`） | 出现工作区行（文件夹图标），点击自动补全 `@工作区名/` 并列出该工作区笔记 |
| 发送消息 | 消息里保留 `引用笔记 [标题](路径)`；对话里出现可折叠的「上下文注入」行（来源 `md-notes`），展开可见笔记内容 |
| 追问（不再 @） | 模型仍记得笔记内容（注入持久到 compaction） |
| 删除被引用笔记后再发送 | 发送被阻断，提示「<笔记名> 无法找到」 |

---

## 5. 笔记互链（笔记 → 笔记）

| 步骤 | 预期 |
|---|---|
| 笔记 A 正文写 `[[笔记B名]]`（或 `` `笔记B名` ``），保存 | 预览里渲染成可点链接 |
| 点击该链接 | 管理器跳转到笔记 B（含跨工作区） |
| 写 `[[工作区名/笔记B名]]`（跨工作区重名时） | 跳转到指定工作区的笔记 B |
| 同工作区两篇笔记标题重名，写 `[[该标题]]` | 链接最近更新那篇；hover 提示「N 篇同名标题，建议用文件名区分」 |
| 写 `[[不存在的笔记]]` | 保持普通文本（不链接） |

## 6. Git 同步（可选，配置仓库后）

### 6.1 git 图标与状态卡片

| 步骤 | 预期 |
|---|---|
| 配置仓库后打开管理器 | 工作区行出现 git 图标；未配置仓库的工作区不显示 |
| 点工作区行 git 图标 | 展开该工作区的 Git 同步卡片（分支/子路径/最近提交 +「已同步」或「未推送 N 处」）|
| 再点 git 图标 | 收起 Git 同步卡片 |
| git 图标上的圆点 | 远端有更新 → 左下黄点；本地未推送 → 右下红点；两者都没有 → 无圆点 |
| 悬停 git 图标 | 显示两行提示（远端更新数 / 本地未推送数）|
| 底部全局状态行 | 显示「未推送 N 处 · X 个工作区 · Y 个待同步」 |

### 6.2 推送 / 更新 / 冲突

| 步骤 | 预期 |
|---|---|
| 点「推送」 | 按钮行切换成提交信息行（输入框 + 确认/取消）|
| 填提交信息 → 点确认 | 首次自动 clone；提交并推送成功，切回按钮行 |
| 点「取消」 | 切回按钮行，不推送 |
| 改一篇笔记后推送 | 状态从「已同步」变「未推送 N 处」，推送后复原 |
| 本地删一篇笔记后推送 | 弹确认（用本地覆盖/删除远端）→ 远端同步删除 |
| 点「更新」 | 拉取远端，列表刷新（有冲突时弹「用远端覆盖本地」确认） |
| 打开笔记（自动拉取开） | 静默拉取，不覆盖本地修改；有远端更新时 Git 卡片提示「远端有更新」 |

### 6.3 共享仓库子目录固定（改名安全）

| 步骤 | 预期 |
|---|---|
| shared 模式推送一次后，改工作区名，再推送 | 仍推送到**原固定子目录**，不产生新目录、不孤儿化 |
| 仓库根 | 出现 `.dsh-notes-workspaces.json`（`ws.id → 子目录名`）并已 commit |
