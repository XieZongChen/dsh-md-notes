### 🤖 DSH

查到了。dsh 的复制功能取数据的地方是 `packages/client/ui-conversation/src/client/chat/turn-assistant.ts`：

```ts
/** TurnTailNodeView 复制按钮的文本来源 */
export function assistantText(blocks: readonly AssistantBlock[]): string {
  return blocks.flatMap(block => block.kind === 'text' ? [block.text] : []).join('')
}
```

## 结论

dsh 复制助手消息时，**只保留 `kind === 'text'` 的块，reasoning（思考）、tool 等其他块全部丢弃**，然后按顺序拼接文本。调用链：

`TurnTailNodeView`（回答尾部操作行）→ `MessageIconActions` 复制按钮 → `text={assistantText(closing.blocks)}` → 写入剪贴板。

也就是说——我们刚做的「**只保留最终回答（跳过 reasoning）**」与 dsh 复制逻辑**完全一致**：

| 块类型 | dsh 复制（assistantText） | 我们记入（blocksToText） |
|---|---|---|
| `text`（最终回答） | ✅ 保留 | ✅ 保留 |
| `reasoning`（思考） | ❌ 丢弃 | ❌ 跳过 |
| 其它（tool 等） | ❌ 丢弃 | ❌ 忽略 |

一个小差异（不影响行为）：dsh 客户端用的是 `block.kind`（`AssistantBlock` 类型），我们 host 端从会话事件读的是 `block.type`（`ContentBlock`）——同义字段，都是 text/reasoning 判定。

所以现在的记入行为有 dsh 官方实现背书，无需再改。重启 dsh web 后记入测试即可。
